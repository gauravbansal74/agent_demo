# Brand artwork

Put the official brand files here and restart the server. The app picks them up automatically:

| File | Used for | Notes |
|---|---|---|
| `logo.svg` (or `.png`, `.webp`, `.jpg`) | Header | Full logo (symbol + wordmark), artwork meant for a white background. About 36px tall on screen. |
| `mark.svg` (or `.png`, `.webp`, `.jpg`) | Chat avatar and browser tab icon | The symbol on its own, square. Shown on a navy circle. |

Without these files the app falls back to `../logo-placeholder.svg` plus the brand name as text.
Only use artwork you're allowed to use for this demo.
